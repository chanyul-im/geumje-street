# 금제의 거리

미르시티를 배경으로 한 비공식 팬 게임입니다. 칼로스 제국의 황제 샤를로는 배틀을 금하고 포켓몬을 내쫓고, 반란군은 포켓몬과 함께 경비를 뚫으려 합니다. 주인공은 그 반란군에 들어갑니다.

포켓몬은 Nintendo / Game Freak / Creatures의 상표입니다. 이 저장소의 도트는 모두 이 게임을 위해 새로 그린 것이며, 공식 스프라이트·음악·도감 설명을 쓰지 않습니다. 이름과 종족값, 기술 구성은 공개된 식별 정보를 바탕으로 했습니다.

## 어디서나 열기

아이패드, 아이폰, 안드로이드, 컴퓨터 브라우저에서 같은 주소로 들어갑니다.

https://chanyul-im.github.io/geumje-street/

사파리나 크롬에서 공유 → 홈 화면에 추가하면 주소창 없이 열 수 있습니다. 계정 기록은 그 기기의 브라우저에만 남습니다. 폰에서 만든 계정은 컴퓨터에 자동으로 넘어가지 않습니다.

소스: https://github.com/chanyul-im/geumje-street

## 실행

```bash
npm install
npm run dev
```

개발 서버는 `http://localhost:4731` 입니다.

```bash
npm test
npm run build
```

## 조작

- 이동: `W` `A` `S` `D` 또는 방향키, 화면 오른쪽 아래의 패드
- 조사: `E` 또는 조사 버튼. 문, 마리, 센터, 상점, 합체 공방, 동굴, 성에 말을 겁니다
- 기록은 이 브라우저에 계정별로 남습니다. 첫 화면에서 계정을 새로 만들거나 지울 수 있습니다

## 진행

스타팅 대신 지가르데 10% 폼 한 마리를 받고 시작합니다. 라이벌은 없습니다. 길과 와일드존의 포켓몬에게 닿으면 배틀이 되고, 몬스터볼로 잡을 수 있습니다.

지가르데가 레벨업할 때마다 유대가 깊어져 봉인이 하나씩 풀립니다. 여덟 개면 성문이 열립니다. 봉인 넷에 메가링, 여섯에 Z링이 생깁니다. 메가진화와 Z기술은 배틀마다 한 번입니다. 폼체인지와 큐레무 합체는 상태 화면과 합체 공방에서 합니다.

도감은 포켓몬 레전드 Z-A의 미르도감 232마리와, 토요일 동굴의 이차원도감으로 나뉩니다.

황제 샤를로를 이기면 엔딩입니다. 그 다음, 실제 시간(서울)의 토요일마다 동쪽 이차원 동굴이 열립니다. 한 번에 최대 세 마리가 레벨 70으로 이어 나옵니다. 한 마리를 이기면 다음 배틀이 바로 시작됩니다. 동굴에는 요청한 전설과 환상의 포켓몬, 그리고 도치마론·푸호꼬·개구마르가 나옵니다.
